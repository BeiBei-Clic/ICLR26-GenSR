    核心逻辑 (per D-04, 从 CONTEXT.md code_context):
    1. 处理输入形状: 如果 prior_mu.ndim == 1，unsqueeze 为 (1, 512)；记录原始 shape
    2. z = prior_mu.clone()
    3. dt = 1.0 / num_steps (均匀步长)
    4. timesteps = torch.linspace(0, 1, num_steps + 1)
    5. for i in range(num_steps):
         t_val = timesteps[i]
         t = torch.full((B,), t_val, device=device)
         v = dit(z, t, prior_mu)
         z = z + dt * v
    6. 恢复原始 shape（如果输入是 1D 则 squeeze）
    7. return z (z_opt)

    在 torch.no_grad() 上下文中执行。设备从 prior_mu.device 获取。
