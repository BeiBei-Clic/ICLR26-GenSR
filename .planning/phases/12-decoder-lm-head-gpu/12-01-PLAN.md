按照 RESEARCH.md 的 7 个改造点，逐项修改 finetune_lm_head.py：

**1. 添加导入**（文件顶部，import torch 之后）：
```python
import torch.distributed as dist
from torch.nn.parallel import DistributedDataParallel as DDP
```

**2. DDP 初始化**（替换 `device = "cuda" if torch.cuda.is_available() else "cpu"` 那一行，约 line 39）：
照搬 train_fm.py:209-221 的模式：
```python
ddp = "RANK" in os.environ or "LOCAL_RANK" in os.environ
if ddp:
    dist.init_process_group(backend="nccl")
    local_rank = int(os.environ.get("LOCAL_RANK", 0))
    torch.cuda.set_device(local_rank)
    rank = dist.get_rank()
    world_size = dist.get_world_size()
else:
    local_rank = 0
    rank = 0
    world_size = 1

is_master = rank == 0
device = f"cuda:{local_rank}"
```

**3. DDP 包装 lm_head**（在冻结/解冻逻辑之后，optimizer 创建之前，约 line 99 之后）：
```python
lm_head_raw = decoder.lm_head
if ddp:
    decoder.lm_head = DDP(decoder.lm_head, device_ids=[local_rank], output_device=local_rank)
```

**4. Optimizer 改用 decoder.lm_head.parameters()**（约 line 101-104）：
```python
optimizer = torch.optim.AdamW(
    decoder.lm_head.parameters(),
    lr=args.learning_rate,
)
```
注意：当前代码用 `[p for p in decoder.parameters() if p.requires_grad]` 列表推导获取参数。改为 `decoder.lm_head.parameters()` 后，DDP 模式下通过 wrapper 获取参数，单卡模式下直接通过 lm_head 获取。两者语义相同（lm_head 是唯一可训练模块）。

**5. 所有 print 语句加 is_master 判断**：
- 约 line 98: `if is_master: print(f"Decoder: ...")`
- 约 line 107-109: `if is_master:` 包裹 3 行 print
- 约 line 274: `if is_master: print(f"  New best val loss: ...")`
- 约 line 276: `if is_master: print(f"  val_loss: ...")`
- 约 line 280: `if is_master:` 包裹 print
- 约 line 282-283: `if is_master:` 包裹 2 行 print

**6. 验证循环加 rank 0 判断 + dist.barrier()**（约 line 200 的验证循环块）：
在验证循环外层加 `if is_master:` 判断，验证循环结束后加：
```python
if ddp:
    dist.barrier()
```
注意验证循环内部的 `decoder.eval()` / `decoder.train()` 切换也要保留在 is_master 内部。

保存最优权重时使用 `lm_head_raw.state_dict()` 而不是 `decoder.lm_head.state_dict()`，避免 DDP 的 `module.` 前缀问题。

**7. 训练结束清理**（文件末尾，main 函数最后）：
```python
if ddp:
    dist.destroy_process_group()
```

**关键注意事项（per RESEARCH.md pitfalls）：**
- 只包装 lm_head，不包装整个 decoder（92.9% 参数冻结，包装整个 decoder 需要 find_unused_parameters=True，性能差）
- 保存用 lm_head_raw（未包装的原始引用），不用 DDP wrapper 的 state_dict
- 验证循环在训练步骤之后运行（DDP 首次 forward 必须是 training 模式）
- 数据生成 env.gen_expr() 天然随机，每个 rank 独立生成不重叠数据，无需 DistributedSampler
