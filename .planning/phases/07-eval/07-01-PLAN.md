**CLI 参数（使用 argparse，parents=[get_parser()]）：**
- `--datasets_dir`: 默认 "datasets/pmlb/datasets"
- `--summary_tsv`: 默认 "datasets/pmlb/pmlb/all_summary_stats.tsv"
- `--model_path`: CVAE checkpoint 路径，默认 "weights/checkpoint.pth"
- `--dit_checkpoint`: DiT checkpoint 路径，默认 "weights/fm_best.pth"
- `--output_csv`: 输出 CSV 路径，默认 "experiments/pmlb/GenSR_dit/pmlb_dit_results.csv"
- `--dataset_limit`: 限制数据集数量，默认 -1（全部）
- `--max_rows`: 限制每数据集行数，默认 -1
- `--device`: 默认 "cuda:0"
- `--num_steps`: DiT Euler 积分步数，默认 16（per D-04）

**模型初始化（直接内联，参照 pmlb_batch_inference.py 第 80-141 行）：**
```python
# 设置 params 属性
args.batch_size = 1
args.max_input_dimension = 10
args.env_base_seed = 2023
args.n_dec_layers = 16
# ...（参照 pmlb_batch_inference.py 的完整 params 设置列表）

# 构建 env 和 modules
env = build_env(args)
env.rng = np.random.RandomState(0)
modules = build_modules(env, args, mode='eval')
reload_model(modules, str(model_path))
model = VAESymbolicRegressor(params=args, env=env, modules=modules)
model.to(args.device)

# 加载 DiT
dit = GenSRDiT().to(args.device)
load_checkpoint(dit, args.dit_checkpoint)
```

**数据集发现（复用 pmlb_batch_inference.py 的逻辑，第 142-168 行）：**
1. 读取 all_summary_stats.tsv，筛选 task=="regression" 且 n_categorical_features==0
2. 遍历 datasets_dir，检查 metadata.yaml 中 task=="regression"
3. 筛选 n_features <= max_input_dimension

**评估循环（对每个数据集）：**
1. 检查 output_csv 是否已有该数据集结果（断点续传，per D-03 结果目录）
2. read_file() 加载数据
3. 可选 max_rows 截断
4. 检查 X.shape[1] <= max_input_dimension
5. y = np.expand_dims(y, -1)
6. train_test_split（test_size=0.25, random_state=14423）
7. StandardScaler 拟合 x_to_fit
8. 计时开始：t0 = time.time()
9. 调用 dit_inference(X_scaled_to_fit, y_to_fit, env, args, model, dit, num_steps=args.num_steps)
10. 计时结束：elapsed = time.time() - t0
11. 记录结果到 row dict

**CSV 格式（简化版，per 用户决定 D-02 不需要 CMA-ES 对比）：**
```
dataset,status,n_features,r2,complexity,seconds,error,expr
```

**运行结束统计（打印到终端）：**
- 总数据集数、成功数、失败数
- 平均 R^2、中位 R^2
- R^2 > 0.99 的成功率（per EVAL-03）
- 平均推理时间（per EVAL-02）
- 平均复杂度（per EVAL-01）

- 不要做函数封装（per CLAUDE.md），直接内联所有逻辑在 __main__ 中

- 使用 `from dit_train.train_fm import load_checkpoint`
- sys.path 设置参照 pmlb_batch_inference.py 第 13-15 行
