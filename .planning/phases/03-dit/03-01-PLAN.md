   - exponent = -log(10000) * arange(half_dim) / half_dim

3. **TimestepEmbedding(nn.Module)** — 参照 Cola lines 135-159：
   - __init__(self, sinusoidal_dim, hidden_dim, output_dim)
   - proj_in = Linear(sinusoidal_dim, hidden_dim)
   - proj_hid = Linear(hidden_dim, hidden_dim)
   - proj_out = Linear(hidden_dim, output_dim)
   - act = SiLU()
   - forward(self, timestep, device, dtype): _get_sinusoidal_embedding → act(proj_in) → act(proj_hid) → proj_out
   - timestep 处理：非 tensor 转 tensor，0D 转 1D

4. **AdaLN(nn.Module)** — 参照 Cola lines 310-348，大幅简化：
   - __init__(self, dim, emb_dim): self.proj = Sequential(SiLU(), Linear(dim, 3 * dim))
   - forward(self, x, emb, residual=None): shift, scale, gate = proj(emb).chunk(3, dim=-1)
   - **"in" 模式（归一化+调制）**: return LayerNorm(dim)(x) * (1 + scale) + shift
   - **"out" 模式（门控+残差）**: return x * gate + residual
   - 注意：不需要像 Cola 那样用 hid_shape 展开，因为 GenSR 的 batch 维度是标准的 (B, L, D)
   - 直接内联，不拆 in/out 为独立方法

5. **MLP(nn.Module)** — 参照 Cola lines 355-364（per D-05 GELU）：
   - __init__(self, dim, expand_ratio): Linear(dim, dim*expand_ratio) → GELU("tanh") → Linear(dim*expand_ratio, dim)
   - forward(self, x): 直接三行链式调用

6. **patchify / unpatchify** — 不做类封装（per 项目规范：非复用不封装）：
   - 在 GenSRDiT.forward 中直接用 reshape：
     - patchify: z_t (B, 512) → reshape (B, num_patches, patch_dim)
     - unpatchify: output (B, num_patches, patch_dim) → reshape (B, 512)

不需要创建 PatchIn1D/PatchOut1D 类。patchify/unpatchify 就是简单的 reshape 操作，在 GenSRDiT.forward 中直接写。

1. **GenSRDiTBlock(nn.Module)** — 参照 ColaDiTBlock (lines 479-531)，添加 cross-attention (per D-03):

   __init__(self, hidden_dim, num_heads, emb_dim, ffn_expand_ratio):
   - self_attn_norm = LayerNorm(hidden_dim, elementwise_affine=False)   (per D-06)
   - self_attn: 标准 multi-head self-attention
     - proj_qkv = Linear(hidden_dim, hidden_dim * 3)
     - proj_out = Linear(hidden_dim, hidden_dim)
     - head_dim = hidden_dim // num_heads
   - cross_attn_norm = LayerNorm(hidden_dim, elementwise_affine=False)   (per D-06)
   - cross_attn: cross-attention (per D-03, z_t patches 做 Q, prior_mu 做 K/V)
     - proj_q = Linear(hidden_dim, hidden_dim)  # Q from z_t patches
     - proj_kv = Linear(hidden_dim, hidden_dim * 2)  # K,V from prior_mu
     - proj_cross_out = Linear(hidden_dim, hidden_dim)
   - mlp_norm = LayerNorm(hidden_dim, elementwise_affine=False)   (per D-06)
   - mlp = MLP(hidden_dim, ffn_expand_ratio)
   - ada = AdaLN(hidden_dim, emb_dim)  # 一个 AdaLN 实例，用于所有调制

   forward(self, x, emb, cond):
   - x: (B, num_patches, hidden_dim)
   - emb: (B, hidden_dim) — timestep embedding
   - cond: (B, 1, hidden_dim) — prior_mu 投影后的条件

   流程（参照 ColaDiTBlock，AdaLN in/out 配对）:
   ```
   # Self-attention sub-block
   h = ada(attn_norm(x), emb)                    # AdaLN in: scale/shift
   h = self_attn(h)                               # standard MHA on patches
   x = ada(h, emb, residual=x)                    # AdaLN out: gate + residual

   # Cross-attention sub-block (per D-03)
   h = ada(cross_attn_norm(x), emb)               # AdaLN in
   h = cross_attn(h, cond)                         # Q=x, K=V=cond
   x = ada(h, emb, residual=x)                     # AdaLN out

   # FFN sub-block
   h = ada(mlp_norm(x), emb)                       # AdaLN in
   h = mlp(h)                                      # GELU FFN
   x = ada(h, emb, residual=x)                     # AdaLN out
   ```
   注意：self-attention 使用标准缩放点积注意力，无 RoPE (per D-07)、无 causal mask (per D-07)、无 KV cache (per D-07)。直接用 torch 的 F.scaled_dot_product_attention 或手写 matmul softmax。
   cross-attention: Q = (B, num_patches, hidden_dim) reshaped to (B*num_heads, num_patches, head_dim), K/V = (B, 1, hidden_dim) reshaped to (B*num_heads, 1, head_dim)。

2. **GenSRDiT(nn.Module)** — 参照 ColaDiTModel (lines 548-712)，顶层模型:

   __init__(self, config=None):
   - config = config or dit_default_config (per D-04/D-05)
   - 从 config 提取所有参数
   - self.patch_proj_in = Linear(patch_dim, hidden_dim)  — patchify 后线性投影到隐藏维度

   - self.timestep_emb = TimestepEmbedding(sinusoidal_dim=timestep_embed_dim, hidden_dim=hidden_dim, output_dim=hidden_dim)
   - self.blocks = ModuleList([GenSRDiTBlock(...) for _ in range(num_layers)])
   - self.final_norm = LayerNorm(hidden_dim)  — 最终归一化
   - self.patch_proj_out = Linear(hidden_dim, patch_dim)  — 输出投影回 patch 维度
   - 初始化：patch_proj_out 的 weight 和 bias 设为 0（AdaLN-Zero 输出初始化，per Cola PatchOut1D）
   - 初始化：AdaLN 的 proj 最后一层 weight 和 bias 设为 0（在 GenSRDiTBlock 中处理）

   forward(self, z_t, t, prior_mu):
   - z_t: (B, latent_dim) → reshape (B, num_patches, patch_dim) → patch_proj_in → (B, num_patches, hidden_dim) (per D-02, D-04)
   - t: (B,) → timestep_emb → (B, hidden_dim)
   - prior_mu: (B, latent_dim) → cond_proj → (B, hidden_dim) → unsqueeze(1) → (B, 1, hidden_dim) (per D-03)
   - for block in self.blocks: x = block(x, emb, cond)
   - x = final_norm(x)  (per Cola txt_out_norm)
   - x = patch_proj_out(x)  → (B, num_patches, patch_dim)
   - output = reshape(x, (B, latent_dim))  → (B, 512) (per D-03, DIT-03)
   - return output
